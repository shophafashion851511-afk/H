                  Lập Trình Nút Bấm Trong Widget Thực Thi Lệnh Thay Đổi Website (AJAX)
                
                
Đoạn mã đầy đủ gồm: Tạo nút trong Admin Widget + Xử lý AJAX PHP lưu trạng thái CSDL + Tác động thay đổi hiển thị ra ngoài Website (Frontend).

              

              
            

            
<?php
/**
 * VÍ DỤ: Tạo Nút Bấm "Bật/Tắt Khuyến Mãi Khẩn Cấp" trong Admin Widget
 * Khi admin bấm nút -> Gửi AJAX -> Cập nhật Database -> Website ngoài thay đổi ngay lập tức!
 */

// 1. Tạo Widget trong Admin chứa Nút Hành Động
add_action('wp_dashboard_setup', 'add_actionable_sales_widget');
function add_actionable_sales_widget() {
    wp_add_dashboard_widget(
        'actionable_sales_widget_id',
        '⚡ Điều Khiển Khuyến Mãi Website Trực Tiếp',
        'render_actionable_sales_widget'
    );
}

function render_actionable_sales_widget() {
    $promo_active = get_option('site_promo_active', 'no');
    ?>
    <div style="padding: 10px; font-family: sans-serif;">
        <p style="font-size: 13px;">Trạng thái Khuyến Mãi Trang Chủ: 
            <strong id="promo-status-text" style="color: <?php echo $promo_active === 'yes' ? '#10b981' : '#ef4444'; ?>;">
                <?php echo $promo_active === 'yes' ? 'ĐANG BẬT (Đang chạy ngoài Web)' : 'ĐANG TẮT'; ?>
            </strong>
        </p>
        <button id="btn-toggle-promo" class="button button-primary" style="background: #2563eb; border: none; padding: 6px 14px; border-radius: 6px; cursor: pointer; color: white;">
            <?php echo $promo_active === 'yes' ? '🔴 Tắt Khuyến Mãi Ngay' : '🟢 Bật Khuyến Mãi Ngay'; ?>
        </button>
        <span id="promo-ajax-spinner" style="display:none; margin-left: 10px; font-size: 12px; color: #94a3b8;">⏳ Đang lưu...</span>

        <script>
        jQuery(document).ready(function($) {
            $('#btn-toggle-promo').on('click', function() {
                $('#promo-ajax-spinner').show();
                $.post(ajaxurl, {
                    action: 'toggle_site_promo_action',
                    nonce: '<?php echo wp_create_nonce("toggle_promo_nonce"); ?>'
                }, function(response) {
                    $('#promo-ajax-spinner').hide();
                    if(response.success) {
                        location.reload(); // Tải lại trang Admin để cập nhật nút
                    }
                });
            });
        });
        </script>
    </div>
    <?php
}

// 2. Xử Lý Lệnh AJAX Ở Backend PHP (Lưu dữ liệu vào Database)
add_action('wp_ajax_toggle_site_promo_action', 'handle_toggle_site_promo');
function handle_toggle_site_promo() {
    check_ajax_referer('toggle_promo_nonce', 'nonce');
    if (!current_user_can('manage_options')) {
        wp_send_json_error('Không có quyền quản trị!');
    }

    $current = get_option('site_promo_active', 'no');
    $new_status = ($current === 'yes') ? 'no' : 'yes';
    update_option('site_promo_active', $new_status);

    wp_send_json_success(['status' => $new_status]);
}

// 3. Sử Dụng Trạng Thái Này Để Tác Động Ra Trang Chủ Website (Frontend)
add_action('wp_body_open', 'show_promo_banner_on_frontend');
function show_promo_banner_on_frontend() {
    if (get_option('site_promo_active') === 'yes') {
        echo '<div style="background: #dc2626; color: white; text-align: center; padding: 10px; font-weight: bold; position: sticky; top: 0; z-index: 99999;">
                🔥 SIÊU KHUYẾN MÃI ĐANG BẬT: GIẢM GIÁ 20% TOÀN BỘ ĐƠN HÀNG HÔM NAY! 🔥
              </div>';
    }
}
?>

               Hướng Dẫn Tùy Biến Cho Nền Tảng Khép Kín (SaaS)
            

            

              Các kênh bán hàng như Shopify, Haravan hay Sapo bảo vệ trang quản trị Admin gốc để đảm bảo an toàn tuyệt đối. Để chèn nội dung vào trang quản trị các kênh này, bạn có thể áp dụng 2 cách chính thức:
            


            

              

                Cách 1: Sử dụng App Khối Ghi Chú / Admin Notice
                

                  Cài đặt các ứng dụng miễn phí trên App Store như Admin Notes, Dashboard Announcement Banner hoặc Internal Team Notes. Các app này cho phép bạn đăng thông báo nội bộ cho nhân viên ngay khi đăng nhập trang Admin.
                

              


              

                Cách 2: Chèn qua Admin Extension / Custom App
                

                  Nếu bạn là Lập trình viên (Developer), bạn có thể dùng Shopify Admin Action / Block Extensions hoặc Haravan Partner API để tạo một ô widget tùy chỉnh hiển thị trong trang chi tiết đơn hàng hoặc bảng điều khiển chính.
                

              

            

          

        

      


      
      

        

           Các Bước Tích Hợp Vào Website
        


        

          

            
1

            
Bước 1: Chọn mẫu code

            

              Sử dụng bộ công cụ ở trên để tạo nội dung thông báo & widget đúng nội dung mong muốn của đội ngũ Sales.
            

          


          

            
2

            
Bước 2: Dán mã nguồn

            

              Đối với WordPress: Mở file functions.php hoặc dùng Plugin Code Snippets / WPCode để dán mã PHP vào.
            

          


          

            
3

            
Bước 3: Tải lại trang Admin

            

              Đăng nhập vào trang quản trị kênh bán hàng của bạn để kiểm tra khối thông báo và widget mới xuất hiện.
